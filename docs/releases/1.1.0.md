## Inkwell 1.1.0

Обновление по воздуху — снова по своему каналу и с проверяемым манифестом.

- OTA: канал обновлений задаётся `platformio.ini` (`[crosspoint] repository`) — только релизы
  Inkwell. Прошивка больше не спрашивает релизы апстрима Kapfilm/Paperio-Reader.
- Установка проверяет `firmware-manifest.json`: берёт запись для своей платы (X3 или X4), требует,
  чтобы имя скачиваемого ассета совпадало с манифестом, и сверяет SHA-256 потока до активации
  слота. Без манифеста или при расхождении — отказ, загрузка не переключается.
- Релиз публикует один образ под несколькими именами: `inkwell-<версия>.bin`, `firmware.bin`,
  `firmware-x3.bin`, `firmware-x4.bin` — это одни и те же байты. X3 и X4 работают с одного образа,
  плата определяется в рантайме; X4 Classic и X4 Pro не поддерживаются.
- В каждом релизе: `firmware-manifest.json` (версия, коммит, файлы, размеры, SHA-256, платы),
  `SHA256SUMS` и отладочные артефакты `bootloader.bin`, `partitions.bin`, `firmware.elf`,
  `firmware.map`. Манифест генерируется из самих файлов и проверяется до публикации — расхождение
  хэша валит сборку релиза.
- Документация: README — какие платы поддерживаются, как ставить, как устроена миграция;
  AGENTS.md — инвариант «OTA только из нашего канала».
- Проверки: сборка `pio run -e default` (Flash 5 042 399 Б, 76,9 %; RAM 55 996 Б, 17,1 %),
  `ctest` 831/831, host-тесты OTA 20/20, смоук в QEMU — 8 кадров, без паники.

Установка с SD-карты: положите `inkwell-1.1.0.bin` (или `firmware.bin`) в корень карты и выберите
«Настройки → Обновление → Обновление прошивки с SD-карты».

По воздуху: «Настройки → Обновление». С версии 1.0.0 обновление ставится по воздуху; устройство
с прошивкой Paperio Reader 2.3.x переходит на Inkwell только с SD-карты — по воздуху сработает
защита от понижения версии.
