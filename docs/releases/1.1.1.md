## Inkwell 1.1.1

Исправление обновления по воздуху: проверка обновлений больше не роняет устройство,
а канал релизов доступен прошивке.

- Исправлено: перезагрузка при проверке обновлений. Причина — восьмикилобайтного стека
  Arduino loopTask не хватало: WiFi-ассоциация, TLS-рукопожатие и форматирование логов идут
  по одной стопке, переполнение портило соседние структуры (в отчётах — падение в `snprintf`,
  а в релизной сборке — в `vPortEnterCritical` посреди lwIP TX). Стек loopTask увеличен до
  16 КБ (`SET_LOOP_TASK_STACK_SIZE`), в лог добавлен запас стека в OTA-пути.
- Исправлено: канал OTA. Репозиторий стал публичным, поэтому анонимный GitHub API отдаёт
  релизы (раньше прошивка получала 404 и показывала «Network error»).
- Ожидаемый SHA-256 теперь берётся из `digest` метаданных релиза — проверка обновлений
  обходится одной HTTPS-сессией; `firmware-manifest.json` остаётся fallback и артефактом
  релиза для клиентов. Перед каждой сетевой сессией проверяется свободная куча (иначе
  понятная ошибка вместо падения), длина потока сверяется перед активацией слота.
- Ассеты релиза: `inkwell-1.1.1.bin`, псевдонимы `firmware.bin`/`firmware-x3.bin`/`firmware-x4.bin`
  (один и тот же образ для X3 и X4), `firmware-manifest.json`, `SHA256SUMS`, а также
  `bootloader.bin`, `partitions.bin`, `firmware.elf`, `firmware.map`.
- Проверки: host-тесты 831/831, тесты OTA 24/24, смоук в QEMU — 8 кадров без паники.

Установка с SD-карты: положите `inkwell-1.1.1.bin` (или `firmware.bin`) в корень карты и выберите
«Настройки → Обновление → Обновление прошивки с SD-карты».

По воздуху: «Настройки → Обновление». С 1.0.0 обновление ставится по воздуху; устройство
с прошивкой Paperio Reader 2.3.x переходит на Inkwell только с SD-карты — по воздуху сработает
защита от понижения версии.
