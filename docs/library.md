# Библиотека — главный экран Inkwell

Библиотека (`ShelfActivity`) — стартовый экран прошивки: сюда ведут загрузка устройства,
выход из читалки и все служебные экраны, когда возврат идёт «на главный». Старого главного
экрана (`HomeActivity`) в прошивке больше нет.

## Управление

| Кнопка | Действие |
|---|---|
| Left / Right / Up / Down | перемещение по сетке (3 колонки, до 2 рядов на страницу) |
| **Confirm (короткое)** | открыть **карточку книги** |
| **Confirm (длинное)** | меню над книгой: Открыть, Информация, Обновить обложку, Удалить кэш, Скрыть из библиотеки |
| **Back (короткое)** | поп-ап меню: Файлы, Недавние, OPDS, Передача файлов, Настройки, Скрытые книги, Обновить библиотеку |
| **Back (длинное)** | фильтры и сортировка (автор / серия / жанр / формат / «Все книги», сортировка по названию, автору, последнему открытию) |

Попап меню и списки фильтров рисуются тем же виджетом (`shelfui::drawOverlayList`): в открытом
поп-апе выделение двигают и боковые кнопки, и передняя пара Left/Right, по кругу. Длинные
списки значений (авторы, серии) прокручиваются окном, выделение всегда видно на экране.
Пункта «Библиотека» в меню нет: библиотека и есть экран, над которым меню открывается.

## Карточка книги

Короткое Confirm на карточке — **читать**, длинное — действия с обложкой (установить / вернуть).
Карточка рисуется сразу из данных индекса библиотеки (название, автор, серия, жанр, обложка,
прогресс), а полный разбор файла (описание и точные метаданные) выполняется на следующем тике
и обновляет экран — поэтому открытие не ждёт парсинга EPUB/FB2.

- **Серия** показывается строкой `Серия: #<номер> <название>`; если у серии есть другие книги,
  Left/Right листают их по порядку номеров (книги без номера — в конце, по названию), по кругу.
  Описание при этом листается боковыми Up/Down (подсказки показываются в сайд-слоте).
- **Описание**: EPUB — `dc:description`, FB2 — текст `<annotation>` из самого файла.
- **Прогресс**: полоса и проценты, как в сетке; 100 % — у прочитанной книги.

## Прогресс и «недавно открытые»

Полоса прогресса на ячейке и в карточке читается из `ReadingStatsStore`
(`/.crosspoint/reading-stats.json`) по тому же document id, что использует читалка. Стор
загружается на время построения страницы и применения фильтра, а не один раз при создании
экрана: иначе первый кадр (и сортировка «по последнему открытию») видели пустую историю.

## Скрытые книги

Книга скрывается пунктом **«Скрыть из библиотеки»** в меню книги и возвращается пунктом
**«Скрытые книги»** в меню библиотеки (Confirm на строке возвращает книгу и перестраивает
список, так можно вернуть несколько подряд).

- Скрытые книги не попадают в сетку, в значения фильтров и в переходы по серии.
- Скрытие — это вид, а не удаление: сам файл, кэш и история чтения не трогаются.
- Список хранится в `/.crosspoint/shelf/state.json` (поле `"hidden"`, массив путей) рядом с
  активным фильтром и сортировкой, поэтому переживает «Обновить библиотеку» и перезагрузку.

## Обложки

- Ячейка — фиксированный кадр 3:4 (180×240). Обложка **кадрируется** в этот кадр, поэтому
  белых полос по краям нет.
- Старые тамбы, сгенерированные с полями, удаляются один раз: в каталоге кэша книги
  появляется маркер `.covercrop1`, и тамб пересоздаётся при первом показе.
- Готовые тамбы читаются сразу; отсутствующие генерируются в **фоновой задаче** (`CoverWorker`),
  по одной книге за раз и только для книг видимой страницы — вход в библиотеку и нажатия
  никогда не ждут декодирования картинки.
- Нет обложки — в кадре по центру пишется название книги.
- В правом верхнем углу ячейки — чип формата: `EPUB`, `FB2`, `TXT`, `MD`, `XTC`.

Обложка `.fb2.zip` **не требует полной конвертации книги**: нативный сканер уже индексирует
`<binary>`-секции, поэтому `lib/Shelf/Fb2Cover` вытаскивает только картинку обложки в
`cover.img` (потоково, без `package.epub` и `book.bin`) и она декодируется в тамб. Это делает
генерацию дешёвой и для библиотеки в сотни книг: работа идёт лениво, по видимой странице, а
результат остаётся в кэше книги. Книга без обложки получает sentinel-файл и больше не
опрашивается.

Диагностика: шаги фоновой генерации пишутся в `/.crosspoint/shelf/cover.log` на карте (UART в
эмуляторе обрывается, а карту можно прочитать с хоста через `tools/qemu/sd-files.py`).

## Метаданные

- **Серия** у FB2 берётся из `<sequence>` (имя и номер), у EPUB — из `calibre:series`.
  Карточка показывает `Серия: #<номер> <название>` и листает соседей влево/вправо.
- **Жанр** — первая значимая строка из `<genre>` (FB2) / `dc:subject` (EPUB); фильтр «Жанр»
  работает по этому значению.
- **Описание** — FB2 `<annotation>`, EPUB `dc:description`; для FB2 читается родным сканером
  прямо из архива, без построения EPUB-кэша.

## Индекс и скорость

Индекс библиотеки лежит в `/.crosspoint/shelf/`. Вход в библиотеку показывает кэш сразу,
сканирования SD при входе нет. Пересканировать карту можно пунктом **«Обновить библиотеку»**
в поп-ап меню (или при отсутствии индекса — тогда это первичное построение). «Обновить
библиотеку» делает **полную** пересборку индекса: все файлы перечитываются вместе с сериями
и описаниями, а не только изменённые.

Формат индекса версионирован (`kIndexVersion`): после повышения версии старый кэш считается
нечитаемым и пересобирается автоматически при первом входе в библиотеку.

## Быстрый сон

Быстрый сон (`QUICK_RESUME`) снимает состояние библиотеки
(`ShelfActivity::getSleepState()` → выбранная ячейка) и после пробуждения восстанавливает
её через `ActivityManager::resumeHomeFromQuickSleep`. Возврат «на главный» из читалки и
служебных экранов тоже передаёт индекс фокуса, поэтому библиотека открывается на той же книге.
