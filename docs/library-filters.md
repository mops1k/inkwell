# Библиотека: фильтры, сортировка и карточка книги

Урезанная версия «книжной библиотеки» (план `p_e2f3b165ca94`, фаза Ф4): одна библиотека,
без отдельных полок и правил.

## Управление (важно: все кнопки)

| Где | Кнопка | Что делает |
|---|---|---|
| Библиотека | Влево/Вправо | предыдущая/следующая книга |
| Библиотека | Вверх/Вниз (боковые) | строка сетки |
| Библиотека | Confirm (короткое) | открыть книгу |
| Библиотека | Confirm (долгое) | меню книги: Открыть / Информация / Обновить обложку / Удалить кэш |
| Библиотека | **Back (долгое)** | **меню фильтров и сортировки** |
| Библиотека | Back (короткое) | выход на главный экран |
| Меню фильтров | Вверх/Вниз | выбрать пункт |
| Меню фильтров | Confirm | открыть список значений (Автор/Серия/Жанр) или сразу применить сортировку |
| Меню фильтров | Back | закрыть меню |
| Список значений | Вверх/Вниз | выбрать значение |
| Список значений | Confirm | применить фильтр (`Все книги` в начале списка — сброс) |
| Список значений | Back | вернуться к списку категорий |

Пока фильтр не задан, в шапке библиотеки видна подсказка «Удержание «Назад»: фильтры» —
поэтому жест не нужно запоминать. Активный фильтр показан там же: `Автор: Лев Толстой`.
Выбранный вид сохраняется в `/.crosspoint/shelf/state.json` и восстанавливается при запуске.

## Карточка книги

Открывается долгим Confirm → «Информация». Показывает автора, серию, жанр (если есть),
размер файла, прогресс/время чтения и описание из файла (листается Влево/Вправо).
Confirm в карточке открывает меню: **«Открыть»** (чтение; возврат туда, откуда открыта
карточка — библиотека или главный экран), затем смена/сброс обложки.

## Где что лежит

| Слой | Файл | Ответственность |
|---|---|---|
| Метаданные | `lib/Shelf/BookMetadata.*`, `Fb2Metadata.*`, `XtcMetadata.*` | чтение title/author/series/genre из контейнера |
| Индекс v2 | `lib/Shelf/ShelfIndex.*` | JSON `books.json`; v1 читается, жанр появится после пересканирования |
| Запрос | `lib/Shelf/LibraryQuery.*` | фильтр по одному полю + сортировка, чистые функции без UI |
| Состояние вида | `lib/Shelf/ShelfStateStore.*` | `/.crosspoint/shelf/state.json`, запись `.tmp` + rename |
| Экран | `src/activities/shelf/ShelfActivity.cpp` | меню фильтров, подзаголовок, сетка |
| Оверлей списка | `shelfui::drawOverlayList` в `ShelfGridRenderer.*` | меню книги, категории и значения — один виджет для устройства и `ui_sim` |

Жанр в индексе — **один**: первый `<genre>` FB2 или первый `dc:subject` EPUB
(`BOOK_CACHE_VERSION` поднят до 13, старый `book.bin` пересоберётся сам).

## Проверка без устройства

```bash
cmake -S test -B build/test && cmake --build build/test -j && ctest --test-dir build/test -j

# кадры потока фильтров: библиотека с подсказкой → меню → список авторов → результат
cmake -S tools/ui_sim -B build/ui_sim -DCMAKE_BUILD_TYPE=Release && cmake --build build/ui_sim -j
./build/ui_sim/ui_sim --out /tmp/uisim_ff --scene shelf --theme lyra \
  --scenario tools/ui_sim/scenarios/filter_flow.json
```
